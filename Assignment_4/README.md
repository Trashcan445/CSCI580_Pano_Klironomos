# CSCI580_Pano_Klironomos

To use the code, download the .ipynb notebook from this folder.
Upload the notebook to Google Colab.
Run all code chunks to generate two solutions to TSP, one using Simulated Annealing and one using Genetic Algorithm.
The code will run both algorithms and generate best tour lengths, graphs, and statistics.
